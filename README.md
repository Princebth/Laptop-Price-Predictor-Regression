# Laptop Price Predictor

A Machine Learning web application that predicts laptop prices based on user-selected specifications.

## Features
- Select laptop brand and specifications
- Predict estimated laptop price
- Interactive Streamlit interface
- Docker support for easy deployment

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Docker
